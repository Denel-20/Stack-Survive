# 게임 기획서 v0.3 (가칭: Stack & Survive)

1인 개발 · Unity · PC(스팀) · 작성일 2026-11-07 · v0.3 수정 2026-11-10

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 싱글플레이 배틀로얄 + 실시간 액션 덱빌딩 |
| 시점 | 2D 탑뷰 |
| 엔진 | Unity |
| 플랫폼 | PC (스팀 등) |
| 개발 형태 | 1인 개발 |
| 목표 기간 | 2\~3개월 (출시 준비 3\~4주 포함 권장) |
| 한 판 길이 | 10\~20분 |
| 아트 | 도트 스타일, AI를 통한 직간접 제작 |
| 메타 진행 | 없음 (판 종료 후 영구 보상 없음) |

**한 줄 컨셉**

> 랜덤 파밍으로 카드를 모아 덱을 만들고, 실시간으로 카드를 이어 써서 연쇄를 쌓으며, 줄어드는 안전지대 속에서 마지막까지 살아남는 싱글플레이 배틀로얄 덱빌더

**기획 의도**

덱빌딩 장르의 정적인 약점을 실시간 액션으로 해소한다. 카드 구성이 곧 전투 리듬이 되도록 설계하여, 덱빌딩의 전략성과 액션의 긴장감을 동시에 제공한다.

## 2. 핵심 재미와 코어 루프

파밍으로 카드를 모아 덱을 만든다 → 실시간 전투에서 같은 속성 카드를 이어 써서 연쇄를 쌓는다 → 덱이 비면 재장전의 무방비 시간을 견딘다 → 안전지대가 줄어드는 압박 속에서 끝까지 생존한다

**플레이어가 반복하는 세 가지 선택**

1. 어디서 파밍할 것인가 (위험과 보상)
2. 싸울 것인가, 피할 것인가 (현재 덱으로 이길 수 있는가)
3. 어떤 카드를 덱에 넣고 버릴 것인가 (덱 크기에 따른 연쇄 안정성 vs 다양성)

**게임 진행 3단계**

1. **상자 파밍**: 기본적인 카드, 장비, 가방을 획득한다.
2. **필드 몹 사냥**: 자신의 필드(속성) 방향성을 확정하고 관련 카드를 획득한다.
3. **교전**: 다른 플레이어(봇)와 교전하며 마지막까지 생존한다.

## 3. 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 및 발사 |
| 마우스 휠 | 카드 선택 (순환 방식) |
| 숫자키 1\~6 | 카드 직접 선택 (보조) |
| 스페이스바 또는 Shift | 대쉬 |

**커서 옆 간략 UI**

- 선택된 카드는 크게(아이콘, 속성, 비용 정보), 앞뒤 카드는 작게 커서 옆에 표시한다.
- 쿨다운과 재장전 상태는 커서 주변 링으로 표시한다.
- 카드의 상세 설명은 전투 중이 아니라 일시정지 화면과 파밍 직후 정보 창에서 보여준다.
- 휠 입력은 한 칸당 카드 한 장이 정확히 대응되도록 입력 간 짧은 딜레이를 두고, 선택 변경 시 소리와 짧은 애니메이션으로 피드백한다.

## 4. 카드 시스템

### 4.1 구성

- 속성 4종: **불, 물, 번개, 바위**
- 속성당 10장, 총 **40장**
- 등급 (일반 → 레어 → 고급 순으로 높음): 일반 4장, 레어 4장, 고급 2장
- 모든 카드는 **공격 카드**이며, 공격 종류는 **범위 공격**과 **투사체 공격** 두 가지뿐이다.

### 4.2 속성 정체성 (속성 공통 효과 방향)

| 속성 | 정체성 | 속성 공통 효과 (카드별 설정 없이 동일 적용) |
| --- | --- | --- |
| 불 | 지속 피해 | **화상**: 일정 시간 동안 지속 피해 |
| 물 | 제어 | **침수**: 지속 시간 동안 이동 속도 감소, 대쉬 시 스태미나 추가 소모 |
| 번개 | 속도와 연쇄 | **감전**: 일정 시간 동안 카드를 사용할 때마다 피해 (몬스터는 공격할 때) |
| 바위 | 묵직함 | **충격**: 시전 중인 카드를 취소, 효과 발동 후 2초간 면역 |

### 4.3 카드 데이터 구조

카드는 다음 요소의 조합으로 정의하며, Unity ScriptableObject 데이터로 관리한다. 화상 같은 속성 공통 효과는 카드별로 설정하지 않고 속성 단위로 동일하게 적용한다.

> 속성 + 공격 종류 + 피해량 + 모양 수치 + 시전 딜레이 + 카드 고유 효과

- 투사체 모양 수치: 속도, 관통 여부, 발사 개수
- 범위 모양 수치: 반경, 발동 위치(내 주변 또는 커서 위치), 발동 전 지연 없이 즉시 발동하며 그 대신 시전 딜레이를 길게 둔다

### 4.4 등급 차별화

등급은 단순 수치 증가가 아니라 효과의 질로 구분한다.

- **일반**: 단순하고 믿음직한 효과
- **레어**: 부가 효과가 더해진 카드
- **고급**: 규칙을 바꾸는 효과 (예: 연쇄 스택 가속, 재장전 단축, 다른 속성과 연동)

### 4.5 연쇄 (콤보)

- 같은 속성 카드를 연속으로 쓰면 스택이 쌓여 효과가 강화된다. (초기값: 스택당 +15%, 최대 5스택)
- 다른 속성 카드를 쓰면 스택이 0이 아니라 **현재 스택의 절반으로 감소**한다.
- 한 속성 몰빵이 항상 최적해가 되지 않도록, 서로 다른 속성의 조합 보너스를 고급 카드 효과로 제공하는 방안을 검토한다.

### 4.6 덱과 재장전

- 손패는 최대 **6장**이다.
- 기본 덱 크기는 **12장**이며, 가방 레벨을 올릴수록 **20장, 32장, 40장**으로 늘어난다. 가방은 상자에서 획득하며, 같은 카드는 중복해서 넣을 수 있다.
- 카드는 쿨타임이 아니라 **덱을 소모하는 방식**으로 사용한다. 손패에 올라온 카드를 쓰면 덱에서 새 카드가 채워진다.
- 덱과 손패를 모두 소진하면 덱 크기에 비례해(장당 0.1초, 12장 1.2초 / 40장 4초) **재장전**한 뒤 덱이 다시 채워진다.
- 카드 사용 시 짧은 시전 딜레이(초기값 0.3초)를 두어 연타로 덱을 순식간에 비우는 것을 방지한다.
- 덱이 작을수록 재장전이 빠르고 연쇄가 안정적이며, 클수록 다양하지만 재장전이 길고 연쇄가 끊기기 쉽다. 이 선택이 덱빌딩의 핵심 전략이다.
- 재장전 시간을 줄이는 효과는 파밍 보상으로 제공할 수 있다. 또는 손패의 한 칸을 차지하는 방식도 고려한다. (연사가 가능하지만 연쇄하기 어려워짐)

### 4.7 속성 공통 효과 초기값

| 속성 | 효과 | 초기값 (프로토타입에서 조정) |
| --- | --- | --- |
| 불 | 화상 | 3초간 초당 1 피해, 지속시간 갱신 |
| 물 | 침수 | 2초간 이동 속도 30% 감소, 대쉬 시 스태미나 소모 1.15배 (30 → 34.5), 지속시간 갱신 |
| 번개 | 감전 | 2초간 카드를 사용할 때마다 피해 2 (몬스터는 공격할 때), 지속시간 갱신 |
| 바위 | 충격 | 시전 중인 카드를 취소, 발동 후 2초간 충격 면역 |

- 효과 이름과 수치는 임시값이다.
- 충격으로 취소된 카드는 소모되어 효과 없이 사라지고, 시전 딜레이는 즉시 끝난다. (제안)
- 침수 중 대쉬는 스태미나를 30 대신 1.15배인 34.5만큼 소모한다. 스태미나 100 기준으로 평소 3회 가능한 연속 대쉬가 침수 중에는 2회로 줄어든다. 스태미나가 부족하면 대쉬할 수 없다. 침수는 중첩되지 않고 지속시간만 갱신한다.

## 5. 전투 시스템

### 5.1 대쉬

- 스태미나를 소모해 **WASD 이동 방향**으로 짧게 이동한다. 입력이 없으면 마지막 이동 방향으로 한다.
- 대쉬 **초반 0.2\~0.3초만 무적**이다. (전체 구간 무적이 아님)
- 스태미나는 100을 보유하고 대쉬 1회에 30을 소모한다. (약 3회 분량) 사용 후 약 1초 뒤부터 자동 충전된다.
- **재장전 중에도 대쉬는 가능**하다. 재장전의 위험이 무방비가 아니라 대쉬를 아껴야 하는 판단이 되도록 한다.
- 침수 상태에서는 대쉬의 스태미나 소모가 1.15배(34.5)로 늘어난다. (4.7 참조)

### 5.2 체력과 회복

- 체력 회복은 **필드 아이템으로만** 가능하다. (카드로 회복 불가)
- 회복 아이템은 상자 드롭 풀에서 카드와 함께 나와 "카드 vs 회복" 선택을 만든다.
- 회복 아이템 사용에 1\~2초가 걸리며, 그동안 이동은 가능하나 느려진다. (초기안)
- 회복 시전 중 대쉬하면 회복이 취소되고 대쉬가 실행된다.

### 5.3 공격 예고

대쉬 회피가 의미를 가지려면 모든 공격은 예고가 있어야 한다.

- 범위 공격: 시전 딜레이 동안 바닥에 위험 구역을 표시한다.
- 투사체: 궤적이 명확히 보이도록 한다.
- AI 적: 공격 직전 짧은 준비 동작을 넣는다.

### 5.4 방어구

- 방어구는 **모자**와 **망토** 두 종류뿐이며, 부위당 한 개씩 착용한다. 상자에서 장비로 획득한다.
- 방어구는 획득 시 **무작위 1개 또는 2개 원소**의 내성을 부여하며, 레벨은 1\~3이다.
- 한 속성에 몰빵한 덱이 내성에 막히지 않도록, 방어구에 맞춰 다양한 속성을 쓰게 유도한다. (봇도 동일한 방어구 시스템을 사용한다.)

| 방어구 구성 | Lv1 | Lv2 | Lv3 |
| --- | --- | --- | --- |
| 1원소 | 10% | 15% | 20% |
| 2원소 (원소마다 각각) | 5% | 10% | 15% |

- 모자와 망토의 내성은 같은 원소끼리 **합산**한다. 이론상 최대 내성은 40%이다. (20% + 20%)
- 내성은 해당 원소 카드의 **직접 피해**만 내성 수치만큼 줄인다. 범위 공격 후 남는 장판, 지속 피해, 속성 공통 효과의 피해(화상, 감전 등)는 내성 수치와 무관하며, 지속시간도 줄지 않는다.
- **합산 내성이 35% 이상인 원소는 그 원소의 공통 효과(화상, 침수, 감전, 충격)에 면역**이 된다. 면역은 효과 자체를 받지 않는 것이며, 카드의 직접 피해는 면역이어도 내성 수치(35~40%)만큼만 줄어든다.
- 면역이 되는 조합은 한 부위가 Lv3 1원소(20%)이고, 다른 부위가 같은 원소 15% 이상(1원소 Lv2\~3 또는 2원소 Lv3)인 경우뿐이다. 2원소 방어구 두 개는 최대 30%라 면역이 되지 않는다.
- 무작위 2개 착용 시 면역이 하나라도 생길 확률은 약 5%이다. (1원소/2원소 50:50, 레벨 균등 가정) 드롭 확률은 11장의 미결정 사항에서 정한다.

## 6. 한 판의 흐름 (10\~20분, 15분 기준 초기값)

| 단계 (15분 기준) | 상황 | 플레이어가 하는 일 |
| --- | --- | --- |
| 1. 상자 파밍 (0\~4분) | 전체 맵 안전, 적들이 흩어져 있음 | 상자를 열어 기본적인 카드, 장비, 가방을 얻는다 |
| 2. 필드 몹 사냥 (4\~9분) | 안전지대 축소 시작 | 속성 지역의 몬스터를 사냥해 관련 카드를 얻고, 덱의 속성 방향을 확정한다 |
| 3. 교전 (9\~15분) | 안전지대가 좁아져 강제 교전 | 만든 덱으로 다른 플레이어(봇)와 교전하며 마지막까지 생존한다 |

## 7. 맵

고정 레이아웃 맵 하나를 제작하고, 랜덤성은 상자와 아이템 위치, 몬스터 배치, 플레이어와 봇의 시작 위치로 만든다. 크기는 화면 약 4×4개 분량으로 시작한다.

| 지역 | 몬스터 카드 드롭 | 분위기 |
| --- | --- | --- |
| 화산 지대 | 불 카드 확률 높음 | 용암, 붉은 톤 |
| 호수 지대 | 물 카드 확률 높음 | 물가, 푸른 톤 |
| 폭풍 지대 | 번개 카드 확률 높음 | 평원, 노란 톤 |
| 암석 지대 | 바위 카드 확률 높음 | 협곡, 갈색 톤 |

- 중앙은 4구역이 만나는 곳으로, **고급 카드가 나오는 위험 지역**이다.
- 상자에서는 기본적인 카드, 장비(방어구), 가방, 회복 아이템이 나오고, 속성 지역의 몬스터가 해당 속성 카드를 드롭해 사냥으로 덱의 방향성이 정해진다.
- 지역 편향으로 "어느 지역에서 사냥을 시작할까"가 속성 방향을 정하는 선택이 된다.

| 단계 | 시작 시각 (15분 기준, 판 길이에 비례해 조정) | 내용 |
| --- | --- | --- |
| 대기 | 0:00\~4:00 | 전체 맵 안전 |

| 2차 축소 | 8:00 | 약 35% |

- 원형으로 줄어들며 다음 안전지대 위치는 미리 화면에 표시한다.
- 안전지대 밖에서는 지속 피해를 받고, 단계가 갈수록 피해가 커진다.
- 축소 방향이 매번 달라져 같은 맵에서도 판마다 상황이 달라진다.

## 9. AI와 몬스터

### 9.1 봇

- 봇 9명 + 플레이어 = 10명으로 시작한다.
- 봇은 **플레이어와 동일한 카드와 공격 시스템**을 사용하고, 판단 로직만 추가한다.
- 행동 상태: 파밍 → 안전지대로 이동 → 교전 → 회복/도주
- 난이도는 조준 오차, 반응 속도, 대쉬 사용 빈도로 조절하고, 성격(공격적, 신중함 등)은 값으로만 차이를 둔다.
- 인원 감소를 위해 봇끼리 교전하게 한다. 멀리 떨어진 봇은 간단한 시뮬레이션(만나면 확률로 승패 결정)으로 처리하는 방안을 검토하며, 초기에는 생략할 수 있다.

### 9.2 사냥용 몬스터

1. **일반 몬스터**: 돌진형 또는 투척형. 처치 시 해당 속성의 일반 카드를 드롭하고, 드물게 레어 카드를 드롭한다.
2. **엘리트 몬스터**: 돌진과 투척이 섞인 복합 패턴. 속성 지역(필드)당 1마리가 있으며, 처치 시 해당 속성의 고급 카드 1장을 확정으로, 레어 카드를 몇 장 드롭한다.

일반 몬스터의 돌진형과 투척형 패턴은 속성 지역별로 색과 드롭만 바꿔 재사용하고, 엘리트는 지역별로 1종씩 제작해 작업량을 줄인다. (제안)

## 10. 개발 범위와 우선순위 (제안)

**1단계 프로토타입 (핵심 재미 검증)**

- 이동, 조준, 대쉬
- 카드 발사 (투사체/범위), 휠 선택과 커서 옆 UI
- 연쇄 스택, 덱 소진과 재장전
- 더미 적 1\~2종

**2단계**: 카드 40장 데이터화, 상자 파밍, 회복 아이템, 맵 제작

**3단계**: 안전지대, 봇 AI, 몬스터

**4단계**: 밸런스 조정, UI/연출, 사운드, 스팀 페이지와 빌드 테스트

**아트 방향**

- 도트 스타일
- AI를 통한 직간접 제작

## 11. 미결정 사항

- 게임 이름 (임시 이름 Stack & Survive 사용 중, 정식 이름은 스팀 페이지 준비 전에 확정, 스팀 검색으로 중복 확인 필요)
- 가방 획득 규칙 (상자에서 나오는 확률, 한 판 최대 레벨)
- 방어구 드롭 확률 (1원소/2원소 비율, 레벨 비율, 상자·엘리트·중앙 지역별 차이)

- 중앙 지역의 고급 카드와 엘리트의 고급 카드 확정 드롭의 역할 구분
- 카드 40장과 속성 공통 효과의 수치 밸런스 (프로토타입에서 검증)
- 시작 덱 구성 (초반 무력감 방지를 위한 기본 속성 카드)
